# 🛡️ SOC Terminal Simulator v4.0
![SOC Terminal](Simulacion-de-ciberataques-1-1200x900.webp)

### [ 🔗 ¡ENTRAR AL SISTEMA AQUÍ! ](https://johnny43-cloud.github.io/soc-terminal-simulator/)

Un simulador interactivo de ciberseguridad de alta fidelidad inspirado en la estética de TRON y los Centros de Operaciones de Seguridad (SOC) empresariales. Desarrollado 100% desde un dispositivo móvil como parte de mi bitácora de ingeniería de software.

### ⚙️ Características del Sistema:
* 🔑 Autenticación de doble factor simulada (Tokens de 4 dígitos).
* 🚨 Protocolo Lockdown automatizado ante ataques de fuerza bruta o intrusiones.
* 🛡️ Sistema de alertas visuales (Pantalla reactiva intermitente) y sonoras.
* 📋 Registro simulado de direcciones IP en bases de datos locales.

### 🧠 Comandos de Programación Aplicados:
* Bucles de control de estado (`while` / bucles lógicos)
* Operadores lógicos de control (`or` / `and`)
* Sanitización de cadenas de entrada (`.strip()`)
